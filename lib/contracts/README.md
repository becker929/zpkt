# Contracts

The JSON that crosses between the spine's parts. Each part validates its own
output against these files in its tests, so a join cannot drift silently.

| File | Producer | Consumer | Source of truth |
|---|---|---|---|
| `project-config.schema.json` | engineer / a person | hands | generated from `hands/src/hands/models.py` by `hands/scripts/gen_schemas.py` |
| `feedback.schema.json` | hands (vibe) | taste | generated by `hands/scripts/gen_schemas.py` |
| `audio-profile.schema.json` | ears (`ears analyze --json`) | taste, engineer | generated from `ears/src/ears/models.py` by `ears/scripts/gen_schema.py` |
| `verdict.schema.json` | taste | engineer | generated from `prototypes/taste/src/taste/models.py` by `prototypes/taste/scripts/gen_schema.py` |

taste and engineer are prototypes (`prototypes/taste`, `prototypes/engineer`).
hands and ears are called by the engineer through their CLIs; taste is
imported. The engineer's loop test (`prototypes/engineer/tests`) checks the
CLI flags.
