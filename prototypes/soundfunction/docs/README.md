# Documentation

The memory of the project, written down so it survives a container, a
session, or a change of hands. Written 12 September 2026 by the web session
when the mandate moved to the Mac.

| file | what it holds |
|---|---|
| `history.md` | what was built, in order, with dates and durations from the commit record |
| `state.md` | what exists now, where it lives, what is durable and what is ephemeral |
| `decisions.md` | the choices that shape the work and why they were made |
| `lessons.md` | every instrument that turned out bent, how it was caught, what fixed it |
| `how-to.md` | runbooks: publish, lint, test, rebuild the survey, regenerate the register, run each tool |
| `people-and-machines.md` | Anthony, his machines, the repositories, the URLs, the channels |
| `open-items.md` | what is queued, what is blocked, on whom |

The research pages themselves are under `research/`: the hypotheses register,
the two literature reviews, the advice sweep, the knob map, the multitrack
results, the measurement fixes, the plan with dates, and the job specs.
