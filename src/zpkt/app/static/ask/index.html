Improve this app

The agent (Gemini) edits this app's own code. The change is checked, committed and the app restarts into it. If the checks fail twice the change is thrown away. You can always restore an earlier version.

Changes

Every version of this app. Restoring makes a new version with the old files, so nothing is lost.

Feedback

Notes on what to fix or add. “Improve this app” turns them into changes.

Surfaces

Arm a surface to put it on your controller. Starred surfaces are kept in the library and can be recalled into any session.
