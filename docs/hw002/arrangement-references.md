# Arrangement references for the HW002 Short

Collected 1 October 2026. The question: how do artists in this genre cut a track down to a minute?
The audio references (`references.md`) answer how it should sound. These answer how it should be shaped.
Nothing was downloaded; everything here streams free at the links.

## Best match: label previews ("demos")

Labels in this scene post one preview per release.
Each track on the EP gets cut to a short excerpt, and the excerpts run back to back.
These are professionals condensing full tracks, the same job as the Short.

## What this suggests for the Short

- The label demos give 42–60 s per track for NineTimesNine, and 77+ s for SNTS. A 60 s Short sits inside that range.
- Shorts that travel run under 35 s and, by their descriptions, centre on one drop.
- Whether any label demo fits a peak → break → peak arc into its slot is unknown. That needs listening; the audio was not analysed.
- So the current 60 s demo is longer and more eventful than what performs on Shorts. That is data for Anthony's call, not a change to the plan.
