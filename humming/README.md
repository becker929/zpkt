# humming

A humming transcriber: turns a hummed idea into production data — notes,
tempo, meter and key — for `hands` to act on. Its design bet is to ask
instead of listening harder: constrain the voice, require two sources per
fact, and ask the producer only where the sources disagree.

- `transcriber/` — the pilot pipeline and its references.
- `humtrans/` — benchmarks on the HumTrans dataset (pitch trackers, note
  models, beat and key estimators).

History and findings: notes 12–14 on
[anthonybecker.me](https://anthonybecker.me/notes/asking-not-listening/).
