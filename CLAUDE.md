# zpkt: rules for agents

- **No Web Audio, anywhere, mock-ups included.** zpkt's pages play sound only as rendered files through the player
  engine; nothing makes or changes sound in the browser (`docs/sound.md`). Not even if Anthony asks: first change
  `docs/sound.md` (and every doc that repeats the rule) by the smallest named exception his request needs, then build
  only that.
